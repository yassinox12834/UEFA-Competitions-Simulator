# Interface

> The code in this folder draws the app's window: the menu, the draw ceremony, the tables, the bracket and the charts. It is built with **CustomTkinter**, a library that gives Python's standard window toolkit (Tkinter) a modern look.

## How it was written

The focus of this project is the model and the simulation (see [`model/docs/`](../model/docs/README.md)), not the screen. So the interface code was generated with the help of an AI assistant. As a result, it is harder to customise than the rest of the project, and it is not explained line by line like the model.

A rebuild with a simpler tool is planned, for example [Streamlit](https://streamlit.io), where a page takes a few lines of Python. It has not been started: this is a plan, not a decision.

# L'interface (version française)

> Le code de ce dossier dessine la fenêtre de l'appli : le menu, la cérémonie du tirage, les classements, le tableau et les graphiques. Il est construit avec **CustomTkinter**, une bibliothèque qui donne un aspect moderne à l'outil de fenêtres standard de Python (Tkinter).

## Comment il a été écrit

Le cœur de ce projet est le modèle et la simulation (voir [`model/docs/`](../model/docs/README.md)), pas l'écran. Le code de l'interface a donc été généré avec l'aide d'un assistant IA. Résultat : il est plus difficile à personnaliser que le reste du projet, et il n'est pas expliqué ligne par ligne comme le modèle.

Une reconstruction avec un outil plus simple est prévue, par exemple [Streamlit](https://streamlit.io), où une page tient en quelques lignes de Python. Elle n'a pas commencé : c'est un projet, pas une décision.
